# Support

Before reporting a problem:

1. Confirm that Bluetooth is enabled and that no other application is connected to the watch.
2. Trigger the connection from the physical watch using the instructions shown in Actions.
3. Check Connection History and copy only non-sensitive diagnostic text.
4. Reproduce with the latest build from the repository's Actions page or Releases page.

Use a bug report for reproducible defects and a feature request for proposed behavior. Hardware support requests must include the exact model reference and must not include serial numbers or other unique identifiers.

This volunteer project does not provide a warranty, guaranteed response time, official device support, or support on behalf of any watch manufacturer.
